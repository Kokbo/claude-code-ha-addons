# Home Assistant App: Claude Code

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]
![Security rating][security-shield]

Run [Claude Code](https://docs.anthropic.com/en/docs/claude-code), Anthropic's AI coding assistant, in a web terminal in your Home Assistant sidebar. Ask it to write automations, debug integrations or explain your configuration; it can read and edit your config and talk to Home Assistant through hass-mcp.

**This app has full access to your Home Assistant host** (security rating 1). Read the *Security* section of the documentation before installing.

See the **Documentation** tab for setup, options and troubleshooting.
